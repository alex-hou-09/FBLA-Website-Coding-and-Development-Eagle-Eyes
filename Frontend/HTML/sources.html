Sources & Attributions

Development Languages & Frameworks

HTML, CSS, and JavaScript

All used for structure, design, and functionality of website's frontend.

Node.js and Express.js

Node.js provides the JavaScript runtime for building the server side application and handling API logic, while Express.js is a lightweight framework that manages routing, middleware, and HTTP requests for the backend.

Multer

The middleware that processes multipart/form-data, allowing image uploads for lost and found item reports.

Resend

An email delivery service that integrates with the backend to reliably send transactional and notification emails to users.

Learning Resources

Used as a research and learning resource by exploring other developers’ projects, code structures, and documentation. Referencing existing repositories helped inform design decisions, implementation approaches, and best practices while building my own project.

Tools & Libraries

VS Code

Primary development environment used to write, edit, and debug the project’s code efficiently.

Express Session

Session middleware for managing user authentication and maintaining login states across the application.

JSON

Lightweight data interchange format used to structure and transmit data between the frontend and backend that mocks the use of a database.

Project Information

Walnut Hills High School

This project was developed specifically for Walnut Hills High School with the goal of streamlining the way students and staff report, track, and retrieve lost and found items. All information about school policies, procedures, and locations was gathered from the official school website, combined with insights and observations from my own experiences as a student navigating the campus.
