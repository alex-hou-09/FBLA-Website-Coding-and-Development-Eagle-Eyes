Development & Frameworks

HTML, CSS, and JavaScript

All used for structure, design, and functionality of website's frontend.

Node.js and Express.js

JavaScript runtime environment used for building the server-side application and handling API requests. AND Web application framework for Node.js that handles routing, middleware, and HTTP requests for our backend server.

Multer

Middleware for handling multipart/form-data, enabling image uploads for lost and found item reports.

Resend

Email sending company, allowed to send emails to users straight from backend.
