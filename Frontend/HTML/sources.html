Development & Frameworks

Node.js

JavaScript runtime environment used for building the server-side application and handling API requests.

Express.js

Web application framework for Node.js that handles routing, middleware, and HTTP requests for our backend server.

Multer

Middleware for handling multipart/form-data, enabling image uploads for lost and found item reports.

Design & Fonts

Google Fonts - Quicksand

Primary font family used throughout the interface for its clean, modern, and friendly appearance.

Google Fonts - Montserrat

Secondary font used for headings and emphasis, providing strong visual hierarchy.

Google Fonts - Nunito Sans

Additional font family for body text and supporting content across the platform.

Learning Resources

MDN Web Docs

Comprehensive documentation for HTML, CSS, and JavaScript used as reference throughout development.

Stack Overflow

Community-driven platform for troubleshooting and finding solutions to development challenges.

W3Schools

Educational resource for web development tutorials and reference materials.

Tools & Libraries

Express Session

Session middleware for managing user authentication and maintaining login states across the application.

JSON

Data format used for storing and exchanging information between the frontend and backend.
